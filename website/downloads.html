Installation

Simple on every supported platform.

Android

Download the APK, allow installation from your browser or file manager if Android asks, then install normally. Updating over the existing app should preserve local data as long as the app is not uninstalled first.

Windows

The Setup build is the normal choice for installation and in-place updates. The portable ZIP can be extracted and run without a traditional installer.

macOS

Open the downloaded DMG and install AniDash as a normal macOS desktop application. Newer DMG builds published in GitHub releases are picked up automatically by this page.
