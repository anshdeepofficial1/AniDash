Desktop experience

Built for a bigger screen.

The desktop editions use AniDash's desktop navigation and window layout instead of simply stretching the phone interface.

W

Windows edition

Includes native desktop window controls, a normal installer, an optional portable package, desktop navigation and in-app update handling for newer installer builds.

M

macOS edition

Includes the macOS desktop navigation layout, DMG packaging and platform-aware update handling for newer macOS releases.
