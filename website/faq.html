FAQ

Quick answers.

The most common things users need to know before installing AniDash on mobile or desktop.

What is AniDash?

An anime companion for discovery, playback, downloads, Continue Watching, library management and supported manga browsing.

What platforms are available?

Android, Windows and macOS are available now. iOS is still in active production.

How do I download the Windows version?

Use the Windows Setup installer for a normal installation and in-place updates. A portable ZIP is also published when available for users who prefer to run AniDash without a traditional installer.

How do I download the macOS version?

Download the newest available AniDash DMG from the Downloads page. The website automatically finds the latest macOS build published in the official GitHub releases.

Do the website download buttons update automatically?

Yes. AniDash checks recent official GitHub releases and points Android, Windows and macOS buttons to the newest available build for each platform. If the newest release does not yet contain a build for one platform, the newest existing build for that platform remains available instead of showing a broken link.

Do I need an account?

No. Local history and library features can work without an account. AniList connection is optional.

Can I watch offline?

Supported episodes can be saved to device storage for offline playback.

Does AniDash host anime or manga?

No. AniDash is a client application that connects to metadata services and supported or user-selected content sources.

Where do updates come from?

Official builds are published through the AniDash GitHub releases. Android users can also use Orion Store or Obtainium, while Windows and macOS downloads are resolved from the newest available official release assets.

What should I include in a bug report?

Your AniDash version, operating system and device, title and episode, selected source, SUB/DUB choice, and a screenshot or short recording when possible.
