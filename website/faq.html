Help

Frequently asked questions.

Everything you need to know before installing or using AniDash.

Do I need an account?+

No. Local library and progress features work without signing in. Optional external tracking requires a configured account integration.

Does AniDash host anime?+

No. AniDash is a client and catalogue interface. Media availability, language tracks and playback depend on external services, device support and applicable rights.

Can I use it in a browser?+

Yes. AniDash Watch is a separate responsive web app. On iPhone or iPad, use Safari’s Add to Home Screen option. Browser capabilities differ from native apps.

Does it support subtitles and dubs?+

Supported playback can offer Japanese audio with subtitles and English dubs; other languages depend on the selected content and source. There is no guarantee that a particular title has a dub.

Can I sync my list?+

AniList is supported in the native app. The web project includes optional AniList and MyAnimeList integrations, which require their own configured OAuth applications. Exact resume depends on player compatibility.

Where do I get updates?+

Use official GitHub Releases, Orion Store or Obtainium. Install only trusted builds. For a native update, use the same package and compatible signing certificate.

Can I download from the web app?+

The native app has offline download management. The web app is primarily online and does not promise native offline downloads.

Where can I report a problem?+

Open a GitHub issue with the app version, device, operating system, title and episode, and a screenshot if possible. Do not share passwords or private tokens.
