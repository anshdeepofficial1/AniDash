Android installation

  1. Download a compatible APK from the official release.
  2. Open the APK and, only if prompted, allow installation from the trusted browser or file manager.
  3. Install, open AniDash, then turn off the temporary install permission if you no longer need it.
  4. For updates, install a compatible signed release over the existing app. Back up important data before updating.

Check package availability and device compatibility in release notes. No unsupported platform is advertised as a guaranteed download.
