# Exact playback position sync (development branch)
Both website and Android use AniList notes `shx:ep=…&sec=…&dur=…`. Background jobs previously dropped notes and used a constant CURRENT status. This branch schedules account-scoped AniList checkpoints only after reading the current remote entry. The worker verifies the current token's account, skips stale jobs if the remote checkpoint or episode count changed, preserves personal notes and writes exact position. Existing legacy jobs lacking an owner are skipped for AniList. The remote read/write is best-effort, not an atomic compare-and-swap. MAL-only sync remains episode-level; Android offline queue and live device tests remain open. No release or main change.
