# AniDash website design

Product: a native and browser anime companion for discovery, organization, manga and compatible playback.
Character: understated, precise, warm.
World: a quiet cinema lobby with warm ink and printed programmes.
Moments: actual mobile screenshots; restrained web information panel.
Signature: numbered feature stories and a single peach accent.

Design audit and direction follow [unslop](https://github.com/heydamir/unslop) by Damir Sokolovsky, CC BY 4.0. No skill code was copied. Removed decorative gradients, emoji-heavy feature cards, exaggerated claims, fake statistics and inflated labels. Preserve media rights notices, platform caveats and real screenshots.

## Release archive refinement
Audit: raw Markdown, excessive lateral whitespace, undifferentiated background and no release navigation. Direction: a maintained software archive with a subtle paper-grid texture, a version rail, a readable central release and a contextual detail rail. Real dates and release assets only. The notes renderer creates text nodes and validated HTTP(S) links rather than inserting release HTML.
