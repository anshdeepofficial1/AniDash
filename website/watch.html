AniDash Watch

AniDash, on the web.

A standalone browser companion for anime discovery, library management and supported online playback.

Visit web app↗Web project source↗

What the web app includes

The browser edition is separate from the native app.

Discovery & search

AniList-powered catalogue, trending and popular titles, details and episode metadata.

Library & history

Local watchlists, Continue Watching and saved progress on supported browsers.

Playback

Browser video controls and available language preferences for supported media. Playback varies by source, title and browser.

Tracking integrations

Optional AniList and MyAnimeList account connections when the corresponding OAuth setup is enabled.

Manga

Catalogue discovery, licensed publisher links where available and a local CBZ reader.

Responsive PWA

Layouts for phones, tablets and desktops. Install from a compatible browser.

Install on your device

iPhone / iPad

Open the web app in Safari, tap Share, select Add to Home Screen and confirm.

Android

Open it in Chrome and choose Install app or Add to Home screen if available.

Desktop

Open the web app in a supported browser. Use its install option if offered.

The web app requires connectivity for online catalogue and playback. It does not host anime or manga files. External account configuration and media availability can change.
